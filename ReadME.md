# Fredderico Castro's Portfolio

This is the source code for Fredderico Castro's personal portfolio website. The website showcases projects, skills, and contact information.

## Table of Contents

- [Overview](#overview)
- [Features](#features)
- [Technologies Used](#technologies-used)


## Overview

The portfolio website is designed to highlight Fredderico Castro's skills, projects, and contact details. It includes sections for About, Projects, Skills, and Contact.

The live website is hosted at: [Fredderico Castro's Portfolio](https://fcstro.github.io/)

## Features

- **Smooth Scrolling Navigation**: Navigate between sections with smooth scrolling.
- **Responsive Design**: Optimized for both desktop and mobile devices.
- **Dynamic Contact Form**: Integrated with EmailJS for sending messages.
- **Interactive UI**: Hover effects and animations for a modern look.

## Technologies Used

- **HTML5**: Structure of the website.
- **CSS3**: Styling and layout, including animations and responsiveness.
- **JavaScript**: Interactivity and form handling.
- **EmailJS**: For sending messages via the contact form.
